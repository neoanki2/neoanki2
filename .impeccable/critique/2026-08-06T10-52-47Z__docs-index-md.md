# NeoAnki2 website critique

## Executive assessment

The rebuilt website is accepted for release. It no longer resembles a generic generated SaaS landing page: the warm neutral palette, editorial spacing, hairline rules, native screenshots, release ledger, and Shape → Recall → Schedule narrative express NeoAnki2's actual product model. The landing page, download surface, and documentation now share one visual and verbal identity.

The primary user journeys are complete: visitors can understand the product, see the deliberate Anki compatibility boundary, verify the current release, choose Homebrew or the exact versioned DMG, understand the non-notarized first-launch implications, and enter task-oriented or reference documentation. Desktop and 375px layouts have no document-level horizontal overflow.

## Design-specificity verdict

Accepted. The original purple gradient, invented logo, glass badges, equal feature-card grid, decorative glow, and generic CTA slab were category-interchangeable. They have been replaced with product evidence and product-specific claims: structured values instead of HTML documents, a focused recall loop, FSRS scheduling, explicit import boundaries, and actual application states. The forced hero cadence and three-step sequence are familiar editorial devices, but the resulting composition feels authored for NeoAnki2 rather than templated.

## Priority findings

- **P0:** None.
- **P1:** None.
- **P2:** None after correction. The actual versioned download, Homebrew security disclosure, command reflow, mobile drawer semantics, Open Graph project path, and screenshot dimensions all pass.
- **P3:** A one-click Copy control for the Homebrew command would be a convenience improvement. A favicon based on an intentional project-owned asset would improve browser-tab polish; do not reintroduce the fabricated lettermark merely to fill this slot.

## Persona red flags

- **New learner:** No blocker. The main proposition and first steps are clear, and the former contributor-facing feature-matrix bait-and-switch is gone.
- **Existing Anki user:** No blocker. Lack of `.apkg`, `.colpkg`, and HTML/CSS-template compatibility is disclosed before download.
- **Security-conscious Mac user:** No blocker. Ad-hoc signing, lack of notarization, safe direct-launch steps, and the cask's app-scoped quarantine removal are explicit.
- **Documentation reader:** No blocker. Search, focused header navigation, mobile modal drawer, breadcrumbs, and generated local tables of contents support both task and deep-reference use.
- **Maintainer:** No blocker. Release metadata is sourced from the current GitHub release during site builds, and release publishing refreshes the site.

## Minor observations

- The full-size screenshot links are now discoverable through a zoom cursor and accessible labels; a visible text cue could be added later if analytics or user feedback shows missed interactions.
- The site deliberately remains spacious. Further compression should be evidence-led so the Quiet Desk character is not traded for generic density.
- The repository is source-available but currently has no license; the website correctly avoids claiming that it is open source.
